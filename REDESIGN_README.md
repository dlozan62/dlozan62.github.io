# DineCheck redesign

This is a GitHub Pages / Jekyll version of the redesigned DineCheck website.

## Use on your existing website
1. Extract this ZIP.
2. Copy the files inside `dinecheck-redesign` into your existing `dlozan62.github.io` folder, replacing matching files. Keep your existing `.git` folder.
3. Run `git add .`, then `git commit -m "Clean up DineCheck website design"`, then `git push`.
4. Let GitHub Pages finish publishing.

The research, team profiles, sprint documents, and download files are retained. The homepage has been rebuilt, and the shared redesign styles are in `assets/css/redesign.css`.

This package does not change your GitHub repository automatically.
